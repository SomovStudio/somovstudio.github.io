📋 Абонемент — Тарифный план тарификация

После того как были созданы «Типы занятий», добавляются тарифы. Тариф — это совокупность свойств, определяющих абонемент.

1. Переход в раздел «Тарифные планы»

Перейдите во вкладку «Тарифные планы» и нажмите кнопку "+ Добавить тариф".

2. Окно «Добавить тип»

Откроется окно, в котором необходимо сделать определённые настройки.

Поля для заполнения

  • Название — текстовое поле для ввода наименования;
  • Цена — общая цена абонемента;
  • Цена за занятие — цена за каждое отдельное занятие (влияет на расчёт общей цены);
  • Количество занятий — количество занятий (влияет на расчёт общей цены);
  • Расчёт срока — действие абонемента в течение дней или месяцев;
  • Срок в днях — количество дней, в течение которых действует абонемент;
  • Срок в месяцах — количество месяцев, в течение которых действует абонемент;
  • Состав пользователей — определяет, кому будет доступен абонемент (Семья, Дети, Взрослые);
  • Типы занятий — в абонемент включаются типы занятий, созданные в разделе «Типы занятий» [СВЯЗЬ];
  • Включенный уровень тренера — позволяет выбрать уровень тренера, созданный в настройках «Уровни тренера» [СВЯЗЬ];
  • Формат доплаты за уровень выше — определяет формат доплаты за уровень тренера.

3. Заполнение и сохранение

Заполните все поля данными и нажмите кнопку «Сохранить».

4. Список тарифов

Добавьте необходимое количество абонементов (тарифов).
